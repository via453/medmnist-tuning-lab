按两条路线分组：A 复刻现有 GitHub 项目 2 个，B 自建项目 3 个。每个选题均按「任务目标 / 方向匹配 / 基线与调参空间 / 三项交付覆盖 / 工作量与风险」展开。

A-1 复刻 MedMNIST 官方 Benchmark + 调参提升 复刻路线 风险 低—中

任务目标Fork 并跑通 MedMNIST/MedMNIST + MedMNIST/experiments 的 2D 训练/评估链路（已核实两个仓库均存在），在 PneumoniaMNIST（胸片二分类，5,856 张，4708/524/624）或 BreastMNIST（乳腺超声二分类，780 张，546/78/156）上复现官方 baseline，再做系统调参，给出可复现的 AUC / ACC 提升与消融表。
方向匹配双命中：医学影像「预测任务」 + 「基于基础预测模型、通过调参提升预测精度」。数据 28×28、CC 许可、标准 train/val/test 划分，官方自带 evaluator（AUC/ACC），不需要医学背景知识。
基线 / 调参基线：官方 2D 简单 CNN 或 ResNet-18（pip install medmnist 一行取数）。调参空间：学习率 1e-4～1e-2 对数搜索、SGD+momentum / Adam / AdamW、batch 32/64/128、weight decay、dropout、cosine/step 调度、翻转旋转与 Cutout 增强、类别权重（胸片不平衡）、早停 patience、BN 开关、3 个随机种子。输出「超参敏感性排序 + 交互作用」。
三项交付流程图：数据下载 → 标准化/增强 → 模型 → 训练 → 验证 → 调参循环 → 独立测试 → 推理，官方实验脚本可直接反画成框图；GitHub：在自己账号建 medmnist-tuning，README 首行注明 upstream 仓库、License 与「个人改动清单」（应对「严禁抄袭代码」）；运行效果：loss/AUC 曲线、混淆矩阵、ROC、预测样本网格、单张图推理 CLI，现场一条命令可复跑。
工作量 / 风险10–14 h。风险：官方 experiments 代码偏老，与 torch 2.5 有版本适配成本；提升幅度可能只有 1–3 个点、甚至小于种子波动 → 结论必须写成「哪些超参敏感 / 不敏感」，而不是宣称刷点；medmnist 包与 .npz 需联网下载；复刻路线要额外解释「我自己动手做了什么」。

A-2 复刻 milesial/Pytorch-UNet + DRIVE 视网膜血管分割 复刻路线 风险 高

任务目标把 milesial/Pytorch-UNet（单文件 train.py/predict.py，CLI 已暴露 epochs / batch / lr / scale / validation / amp / mask-threshold）从 Carvana 汽车掩码迁移到 DRIVE 眼底血管二值分割（40 张，训练/测试各 20 张，584×565，专家手工血管掩码 + FOV 掩码），跑通训练与预测并调参提升 Dice / IoU。
方向匹配最贴导师字面建议的「医学图像分割」，也对应李沐 D46–48（语义分割 / 转置卷积 / FCN）与 C3 CNN。分割掩码叠色图是全组最直观的演示素材。
基线 / 调参基线：UNet(n_channels=3, n_classes=1) + BCE。调参：--scale（0.5→0.25 降分辨率换 CPU 速度）、lr、batch、epochs、BCE 与 BCE+Dice 损失、FOV 掩码加权、翻转/旋转增强、推理阈值 --mask-threshold 扫描（把「阈值」当超参画 Dice-阈值曲线，是最出彩的一张图）、早停。指标 Dice / IoU / Sensitivity。
三项交付流程图：数据 → FOV/归一化 → patch 切块 → U-Net → 阈值 → 后处理 → 评估；原仓库 README 已有结构说明可改画。GitHub：fork + 自建仓库，README 写清数据获取方式；注意 DRIVE 许可禁止再分发，仓库只能放脚本与结果图，不能放原始图。运行效果：原图 / 金标准 / 预测掩码三联叠色图 + python predict.py -i 01_test.tif --viz 现场推理。
工作量 / 风险18–25 h，五个里最高。风险：CPU 上 584×565 的 U-Net 训练慢，必须缩放或切 patch；DRIVE 官网需注册（可用 OpenDataLab 镜像 CC BY 4.0）；TIF 图像 + GIF 调色板掩码的读取/格式转换是经典坑；血管像素仅约 9%，类别极不平衡；原仓库默认 W&B / AMP / CUDA，需裁剪；最可能在中期验收时只交得出「推理 demo + 少量 epoch」。

B-1 自建「MedMNIST 医学影像分类调参实验室」 自建路线 ★ 首推 风险 低

任务目标不 fork 别人的训练框架，在 d2l-zh 环境里从零写一个 200–300 行的完整项目：数据加载 → 自建 SmallCNN（2–3 个 conv + BN + GAP + FC，另设 MLP 作最低基线）→ 统一 config.yaml → 网格/随机搜索（可选 Optuna）→ 消融表 → 最优模型 → 单图推理与交互演示。核心命题：把同一个基础预测模型，靠系统调参把 AUC/ACC 稳定抬高，并说清是哪些超参在起作用。
方向匹配正中导师第三条（基于基础预测模型，通过调参提升预测精度），同时是医学影像预测任务。且能把你笔记里的概念逐个验证：C1 用训练/测试损失判断该动模型还是动数据、C2 优化器与学习率排程、C3 CNN 参数量、C11 换子数据集看分布偏移、C14 可加剪枝/蒸馏作加分项、C10 可加 Grad-CAM 作加分项。
基线 / 调参基线阶梯：逻辑回归 → MLP → SmallCNN（全部自己写，骨架来自李沐 D10/D23）。调参空间：lr（对数）、optimizer（SGD+mom / Adam / AdamW）、batch、width、BN 开关、激活函数、dropout、weight decay、cosine/step + warmup、增强强度、标签平滑、类别权重、早停 patience、3 个 seed；主数据集锁定 1–2 个（建议 PneumoniaMNIST 主 + BreastMNIST 做泛化验证）。产出：超参重要性排序、敏感性曲线、消融表、调参前后对比柱状图。
三项交付流程图：见下方五泳道框图（README 与 PPT 用同一张，附 SVG/PNG 源文件）。GitHub：新建公开仓库 https://github.com/via453/medmnist-tuning-lab，含 README、requirements.txt、configs/、src/、results/*.csv、figures/*.png、notebooks/、LICENSE，验收前至少 3 次 commit，链接当场可访问。运行效果：python run.py --config configs/best.yaml 打印 ACC/AUC 并生成 4 张图；demo.ipynb 或 Gradio 上传一张图显示预测与置信度；loss 曲线、ROC、混淆矩阵、超参热力图全部由代码现场生成，而非贴静态截图。
工作量 / 风险12–16 h，与 E5 的 14 h 预算吻合；28×28 小图 CPU 单次训练 1–3 分钟 → 可跑 30–60 组配置，调参结论有统计意义。风险：小数据上方差大（尤其 BreastMNIST 仅 780 张），必须 3 seed + 独立测试集；绝不能拿测试集调参（这正是你 C1 自测第三题考过的点）；optuna / medmnist 需 pip 联网安装；范围务必锁死在 1–2 个子数据集，别扩张。

B-2 升级既有 ecg-denoise-lab：1D-CNN 心电节拍分类 + 预处理/模型联合调参 自建（延伸） 风险 中

五、其余四个优先级较低的原因

选题为什么排在后面什么情况下值得升级
A-1（复刻 MedMNIST 官方）技术上几乎和 B-1 一样稳，但复刻路线天然多两层成本：一是上游 experiments 代码偏老、要适配 torch 2.5；二是培训方案明写「严禁抄袭代码」，必须逐条标注 upstream 与本次改动，答辩时还要回答「你和官方 baseline 差在哪」。它更适合当 B-1 的官方对照基线，而不是单独成题。导师明确要求「先复现再改进」；或你想把「复现一致性验证」写成报告亮点
B-2（ECG 平台升级）演示效果五个里最强、领域最熟，但数据风险最大：现有 kai4.csv 只是单条 20 s 信号，训练分类器必须另找带标签数据集（MIT-BIH / PTB-XL），切片与 R 峰对齐会吃掉大量时间；而且容易写成「信号处理工程」而非「深度学习调参」，偏离导师方向。中期验收时间窗太窄。最终大作业由多人合作完成、有人专门负责数据；或导师组直接提供带标签心电数据
A-2（U-Net + DRIVE 分割）最贴「医学图像分割」字面，却是风险最高的一项：CPU 上 584×565 的 U-Net 训练慢、DRIVE 需注册或找镜像、TIF+GIF 调色板掩码格式坑多、血管像素仅约 9% 类别极不平衡、原仓库默认 CUDA/AMP/W&B 要裁剪、许可还禁止把原始图放进仓库。18–25 h 也超出 E5 的 14 h 预算，中期很可能只交得出推理 demo。能稳定使用 431 机房 GPU（培训方案明确可预约），且把范围缩到「缩放至 128×128 + 20 张训练图 + 少量 epoch」
B-3（UCI 表格 MLP）最稳、最快，但 569×30 的小表格天花板低、没有图像可视化，容易被评价为「课程练习」而非占 40% 权重、要求完整实验链路的大作业；也不含医学影像，只占导师建议里最边缘的一块。作为验收前的保底交付，或并入 B-1 当「最低性能基线 / 调参方法论验证」章节
