2.2 划分、许可与指标

要点本项目约定为什么
数据划分只用官方 train / val / test；val 用于选配置，test 全程只评一次你 C1 自测第三题写过「用训练集调参是看答案，换个新数据就不会了」——同理，用 test 调参等于泄题
类别不平衡主指标看 AUC，ACC / F1 作辅助；记录各类别样本数肺炎数据正负比例不均，只看 ACC 会被多数类带偏
随机性每组配置 3 个 seed（如 0 / 1 / 2），报告均值 ± 标准差28×28 小数据上方差大，单次的 +2 个点很可能只是运气
许可与隐私CC 许可，仅教育研究；.npz 放 data/ 并写进 .gitignore；仓库只放脚本与结果图避免仓库体积爆炸，也避免再分发原始数据
评估实现优先用 sklearn.metrics.roc_auc_score / accuracy_score / confusion_matrix 自己算官方 medmnist.evaluator 各版本 API 有差异，自己算最稳、也便于写进报告
临床表述全篇不出现「诊断」「辅助诊断」「临床可用」官方免责声明 + 学术规范

3.3 配置检查清单

4 · 调参对比

这一节是项目的主体：先把基线钉死，再单因子扫描，最后做消融。所有结论都必须来自 runs.csv。

4.1 基线阶梯

层级模型作用预期 AUC（仅作量级参考，不写进结论）
L0多数类常数预测 / 逻辑回归证明任务不是 trivial，也给指标一个地板0.50 / 0.7 上下
L1MLP（28×28 展平 → 128 → 2）最低可训练的神经网络基线略高于 L0
L2SmallCNN（2–3 conv + BN + GAP + FC）正式基线，后续全部调参都基于它主要参照点
L3L2 + 最优超参组合调参后的结果，与 L2 做同表对比目标：稳定高于 L2
别把 L1→L2 的增益算成「调参功劳」。换模型是换假设空间，调参是在同一个模型里拧旋钮。报告里必须分开写：结构对比单独一节，超参对比单独一节。

4.2 超参空间对照表

超参建议取值为什么调它对应已学内容预期现象 / 风险
lr1e-4 / 3e-4 / 1e-3 / 3e-3 / 1e-2最敏感的一个旋钮，先扫它C2 自适应学习率 / 训练技巧过大 loss 发散，过小几乎不动；用对数刻度
optimizerSGD+momentum / Adam / AdamW比较收敛速度与泛化C2 动量 / AdaGrad / RMSProp / Adam 订正SGD 常慢但泛化略好；Adam 快、易过拟合
batch_size32 / 64 / 128影响梯度噪声与 train-test gapC1 训练/测试损失诊断CPU 上大 batch 未必更快，先测耗时
weight_decay0 / 1e-4 / 1e-3正则，压过拟合C1 过拟合 / 权重衰退过大反而欠拟合，看 train 与 val 曲线间距
dropout0 / 0.2 / 0.4同上，另一种正则丢弃法相关章节（编号见第 7 节）小模型上 0.4 可能直接掉点
use_bnon / off训练稳定性C2 批量归一化注意 model.train() / eval() 别切错

conv_width16 / 32 / 64容量与参数量C3 卷积参数量手算容量翻倍≠精度翻倍；把参数量一并记进表
pooling轻池化 / 不用池化小目标是否丢失C3 订正版：医学影像微小结节会在池化中丢失28×28 上堆池化容易把病灶特征抹掉
early_stop_patience3 / 5 / 8防止把 val 过拟合当提升C1 模型选择固定一个值更利于横向比较
