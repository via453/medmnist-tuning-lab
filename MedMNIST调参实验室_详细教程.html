def get_loaders(name, cfg, root=r"C:\Users\Zelvia\.medmnist"):
    CLS = PneumoniaMNIST if name == "pneumoniamnist" else BreastMNIST
    tf_train = T.Compose(cfg["augment_ops"] + [T.ToTensor()])   # 增广只作用于 train

    counts = {s: len(ds[s]) for s in ds}

3.2　SmallCNN 定义与输出尺寸手算

import torch.nn as nn

def build_smallcnn(width=16, bn=True, activation="relu", dropout=0.0):
    act = nn.ReLU if activation == "relu" else lambda: nn.LeakyReLU(0.01)
    def block(cin, cout):
        L = [nn.Conv2d(cin, cout, 3, padding=1)]
        if bn: L.append(nn.BatchNorm2d(cout))
        L.append(act())
        return L
    layers = block(1, width) + block(width, 2*width) + [nn.MaxPool2d(2)] \
             + block(2*width, 4*width) + [nn.AdaptiveAvgPool2d(1), nn.Flatten()]
    if dropout > 0: layers.append(nn.Dropout(dropout))
    layers.append(nn.Linear(4*width, 2))
    return nn.Sequential(*layers)
  • 按 C3 公式 (H−K+2P)/S+1：3×3、padding=1、stride=1 → 28→28；MaxPool2d(2) → 14；AdaptiveAvgPool2d(1) → 1×1×4w → 全连接 2 个 logits。实测前向输出 (N, 2)。
  • 只放一个 2×2 池化：依据笔记 C3 订正版「太小的目标（医学影像的微小结节）会在池化中丢失」，28×28 输入不堆叠下采样。
  • 参数量公式（已用本机 torch 核算）：P = 10w + 18w² + 2w + 72w² + 4w + 8w + 2 + (bn ? 14w : 0)；w=16 / BN 开 = 23,650，w=8 / BN 开 = 6,066，w=32 / BN 开 = 93,378。
  • BN 对应 D28 与 C2；model.train() / model.eval() 切换错误列入第 7 节 #7（C16 笔记里的三个「课上这样说、代码里那样写」之一）。

5　评价指标与基线对照方案

5.1　指标定义（全部用 numpy + pandas 实现，不调用 sklearn）

指标定义 / 实现用途
AUC（主排序）正类得分的平均秩和：AUC = (Σrank(y=1) − n_pos(n_pos+1)/2) / (n_pos·n_neg)，并列得分用 pandas.Series.rank(method="average")单因子排序、显著性判定、Δ 计算
ACC(TP+TN)/N，阈值固定 0.5直观对照；不平衡时不得单独作结论
F1（正类）2·TP / (2·TP + FP + FN)，阈值固定 0.5识别「ACC 虚高」
混淆矩阵TP / FP / FN / TN 四个整数误差类型分析
loss 曲线逐 epoch 的 train_loss 与 val_loss过拟合 / 欠拟合判定（第 7 节 #2 #3）
ROC 曲线对 np.unique(scores) 降序扫阈值算 TPR / FPR，matplotlib 作图三配置叠加对比
辅助量params_total、epoch_seconds、total_seconds成本对照与异常判定
import numpy as np, pandas as pd
def auc_rank(scores, y):
    r = pd.Series(np.asarray(scores)).rank(method="average").values
    npos, nneg = int((y==1).sum()), int((y==0).sum())
    return float((r[y==1].sum() - npos*(npos+1)/2) / (npos*nneg))
# scores = torch.softmax(logits, dim=1)[:,1]；y = 0/1 标签；本机已验证该实现返回正确值

5.2　四级基线对照与 Δ 的定义

  1. B0-0 常数预测器：AUC = 0.5；ACC = train 多数类在 test 中的占比。作为下限，不参与 Δ。
  2. B0-1 / B0-2：只报告绝对值，用来说明「卷积的局部性假设带来多少收益」（C3 三假设）。
  3. B0-3 是唯一对照基准：Δtest_auc = test_auc(config) − mean(test_auc(B0-3, 3 seeds))。
  4. S1 / S2 的排序一律用 val_auc；最终结论只用 S3 的 test_auc。

5.3　显著性判据（固定阈值，不留判断空间）

提升有效 ⟺ Δtest_auc ≥ 2 × std(test_auc(B0-3 的三个 seed))。不满足即为 not_significant，写入 anomaly_flags，结论改写为「该超参不敏感」而不是「有提升」。所有数值保留 4 位小数，三 seed 结果一律报 mean ± std。
