## 一、三段式复盘

### ① 哪些概念从「能讲」变成了「能改、能跑出曲线」

11 月 7 日那晚的四件套（自测 HTML → C1-C16 订正版 → 一页纸版 → 自测笔记）解决的是「读」和「写」，笔记结尾自己写着「还差跑」。这个项目补的就是那一块。具体有四条从纸面落到了数字上：

1. **C2 优化技巧：从「知道 Adam 比 SGD 好」到「知道好多少、在什么预算下好」。** 笔记里写的是动量、自适应学习率、BN、学习率排程各自的作用；现在有了极差表：lr 0.0220、optimizer 0.0204、use_bn 0.0186。同一个 SGD，在 20 轮预算里只有 0.9642，而 Adam 0.9844——但这不是「SGD 差」，是**预算不够**（`s1_07` 跑满 20 轮仍在下降）。这条区分在笔记阶段是写不出来的，必须跑。
2. **C3 卷积：从「会算输出尺寸」到「会用手算参数量校验代码」。** 手算 w32 = 19,042、w64 = 74,946、w16 = 4,914，与 `params` 字段完全一致。这一步的意义是：如果哪天模型结构写错，参数量会立刻对不上，比看 loss 更早发现问题。
3. **C1 模型选择：从「知道要看验证集」到「真的把 test 锁进一个只有一行的 CSV」。** `results/test_final.csv` 全程 1 行、时间戳晚于所有调参实验；看到 test 比 val 差 0.117 ACC，第一反应不是改配置重跑，而是回去查数据来源。这条纪律是这次最实在的收获。
4. **C11 领域自适应：从「协变量偏移是个名词」到「假阳性 17 → 100」。** val 阳性率 74.2%、test 62.5%，同一个模型、同一个阈值 0.5，阴性里的误报率从 12.6% 跳到 42.7%。这比任何定义都好记。

### ② 哪一次实验推翻了我原来的理解

**主推：`mlp_s0/s1/s2` —— MLP 打赢了 CNN。**（`results/structure.csv`）

原来笃定「图像任务 CNN 一定比 MLP 强，因为卷积有局部性和平移等变性」。实测 MLP（100,738 参数）val AUC **0.9928**，比调参后的 SmallCNN（0.9886）还高 0.0042，而且训练快 3 倍（0.74 vs 2.24 min）。

复盘后的解释分两层：一是**容量**（SmallCNN 被 dropout+BN+池化+GAP 压到 19k 参数，本来就偏小；w64 一放开就涨 0.004）；二是**任务性质**（28×28 上肺实变是整片肺野的强度/纹理，本质是全局统计量，正好是全连接第一层最擅长的东西）。所以「CNN 更好」这句话在我这个数据规模上**不成立**，它成立的条件是数据量足够让局部滤波器学到可复用的模式。

连带收获：原来以为「结构 > 调参」只是口号，现在是 +0.008（结构）vs +0.004（调参）的具体倍数。

**并列两条小推翻**（都在 C3 的延长线上）：

- `s1_33` 完全不池化 → 0.9782，比 base 还低。笔记订正版写「医学影像微小结节会在池化中丢失」，我据此以为去掉池化更好，结果相反。订正版结论本身没错，错在我把它用成了绝对命令——**「不堆池化」≠「不用池化」**。
- `s1_23` 加旋转增强 → 0.9821，比不增强（0.9851）低。旋转会把肺野推到画布边缘、填一圈黑边，属于分布外变换。增强不是免费的。

### ③ 下一步想补的一块

按优先级：

1. **容量对齐后的结构对照**（最该补）：结构谱系已经做出 ViT ≈ MLP > CNN 的排序（见 `docs/EXTENSIONS.md`），但三个结构的宽度/深度没对齐到同一参数量，所以「是注意力赢还是容量赢」还没彻底分开。下一步：MLP 宽度扫 64/128/256、ViT 扫 dim，与 CNN w32/w64 在同等参数量下重比。
2. **对抗训练**（C9 的下半场）：已经知道 ε=0.03 就能把 AUC 打到随机，下一步把 FGSM 样本混进训练，画出「鲁棒性 vs 精度」的权衡曲线，看代价是掉多少 val AUC。
3. **迭代剪枝**（C14 的边界）：单次剪 80% 不如直接训 w16，说明彩票假说在当前做法下不成立；下一步做「每次剪 20% + 重训」的迭代版，看能不能把结论翻过来。
4. **终身学习（C13）与跨子集泛化**：Pneumonia 训完接 Breast（546 张），测 EWC 前后的遗忘率。这是唯一一个还没碰过、但成本很低（40 分钟）的模块。
5. **阈值与校准**：先验对齐实验说明「按 test 先验调阈值」最多挽回 1 个百分点，但概率是否可信（ECE）还没查；在 val 上分半拟合温度即可补上。

## 四、自评

- **做到**：从零跑通「数据 → 基线 → 单因子扫描 → 网格 → 三 seed 复跑 → 选优 → test 一次性评测 → 出图 → 归档」全链路，共 51 组主实验 + 25 组延伸实验、约 180 分钟 CPU 机时，全部可复现（13 次等价 base 精确复现 0.984404）。笔记「五件动手的事」里能用的三件（FGSM、剪枝、attention）全部兑现。
- **没做到**：结构谱系虽已做出 ViT ≈ MLP > CNN，但没把三者参数量/深度严格对齐，所以「注意力赢还是容量赢」还没完全分开；没做对抗训练（只测了攻击，没测防御）；没做阈值校准与 ECE；终身学习（C13）与跨数据集泛化仍空着。
- **最大的意外**：三条负结果比正结果更有收获——剪枝 80% 不如直接训 w16、蒸馏三个温度全部没赢从头训、先验只能解释 val/test 落差的 11%。原来以为「这些技巧应该多少有点用」，实测发现**每个技巧都有前提条件**，讲不出前提就等于没学懂。
- **一句话**：这轮最大的收获不是 AUC 从 0.9845 涨到 0.9935，而是学会了**先问「这个差值比噪声大多少」，再看「指标掉了是分布问题还是代码问题」，最后问「这个技巧的前提在我这儿成立吗」**。三条比任何一个超参都值钱。
