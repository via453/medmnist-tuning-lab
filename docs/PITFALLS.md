## 已预先标注的高频坑（尚未实际遇到，不计入上面 2 条）

- **依赖冲突**：裸装 `pip install medmnist scikit-learn` 会经 scipy 把 numpy 顶到 2.x；必须用 `requirements.txt` 钉版本，装完 `pip check`。
- **BN 模式**：`model.train()` / `model.eval()` 切错会让验证指标失真。
- **小图池化**：28×28 上堆池化会抹掉病灶特征（C3 订正版：医学影像微小结节会在池化中丢失）。
- **Windows 多进程**：`num_workers>0` 易报 spawn 错，保持 0。
- **版本漂移**：`medmnist` 各版本的 `Evaluator` / `root` API 有差异，先 `inspect.signature` 再看。
- **类别不平衡**：ACC 虚高而 AUC 不动时，检查 `class_weight` 与标签分布。
- **可复现性**：`random` / `numpy` / `torch` 三处都要设 seed，只设一处结果仍会漂。
- **测试集纪律**：用 test 反复调参等于泄题（C1 自测第三题）。
