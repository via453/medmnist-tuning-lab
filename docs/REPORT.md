## 1. 任务与数据

| 项 | 内容 |
| --- | --- |
| 数据集 | PneumoniaMNIST（MedMNIST v2/v3 官方子集），28×28 单通道灰度胸片 |
| 划分 | 官方固定划分：train 4,708 / val 524 / test 624；**不自行重划** |
| 标签分布 | val 阳性 389 / 阴性 135；test 阳性 390 / 阴性 234（阳性占比 val 0.742、test 0.625） |
| 主指标 | AUC（对类别不平衡与阈值不敏感） |
| 辅助指标 | ACC、F1、混淆矩阵 |
| 纪律 | val 选配置与早停；**test 只评一次**，评完不回头改配置 |
| 许可 | CC BY 4.0，仅用于教育研究，不用于任何临床用途 |

选择 AUC 作主指标的理由：两类样本明显不平衡（val 阳性 74%），ACC 会被多数类拉高——第 2 节 L0 的 0.7424 就是这个陷阱的量化版本。

## 2. 结构对比（换模型，不计入调参功劳）

三个层级用同一套数据、同一套优化设置（Adam / lr 1e-3 / batch 64 / 20 epoch / 早停 patience 5），只有网络结构不同。L1 与 L2 各跑 3 个 seed，报告均值 ± 样本标准差（ddof=1）。

| 层级 | 模型 | 参数量 | val AUC（3 seed） | val ACC（均值） | 单次耗时 |
| --- | --- | --- | --- | --- | --- |
| L0 | 多数类（全判肺炎） | 0 | 0.5000 | 0.7424 | — |
| L1 | MLP：784 → 128 → 2（含 dropout 0.2） | 100,738 | **0.992796 ± 0.000699** | **0.9466** | 0.74 min |
| L2 | SmallCNN：2 conv + BN + 1 次 2×2 池化 + GAP | 19,042 | 0.984537 ± 0.000215 | 0.9313 | 1.17 min |
| L2′ | SmallCNN（`conv_width=64`，第 3 节最优） | 74,946 | 0.988645 ± 0.000490 | 0.9408 | 2.24 min |

**结论一（反直觉，但数据就是这样）：L1 的 MLP 比 L2 的 SmallCNN 高 0.0083 AUC，而且参数量是它的 5.3 倍、训练还更快。**

初始假设是「CNN 有局部性归纳偏置，图像任务应当赢」。实测推翻了它。原因分析与证据：

1. 本数据只有 4,708 张训练图，且分辨率 28×28。CNN 的局部权重共享优势需要足够的数据与分辨率才能兑现，这里两者都不足；而病灶（肺实变）在 28×28 上表现为**整片肺野的强度/纹理统计量**，「全图平均」这类全局特征本身就很有判别力，恰好是 MLP 第一层全连接最擅长的东西。
2. SmallCNN 的正则偏强：dropout 0.2 + BN + 池化 + GAP 四重作用下容量被压到 19,042 参数。`conv_width=64`（74,946 参数）立刻把 AUC 拉到 0.9886，说明**瓶颈在容量而非结构类型**。
3. 因此 L1 的优势至少有一部分来自「容量更大」，不是「结构更适合」。严格区分二者需要做 MLP 宽度对齐实验（见第 6 节）。

这条结果直接改变了本报告的主线：**结构选择带来的收益（+0.008）大于超参调优的收益（+0.004）**。也就是说，调参确实有效、也确实显著，但它是在一个偏小的容量预算里做优化；先确认结构合理、再拧旋钮，才是正确顺序（对应 C1「先看损失曲线再决定动什么」、C3「归纳偏置与参数量」。

> 说明：MLP 只跑了 val 对比，**没有**上 test。test 已用于最终配置的一次性评测，不能再为第二个模型开第二次（第 4.3 节）。

## 3. 超参对比（同一结构内拧旋钮）

### 3.1 扫描设计

固定 `SmallCNN + light pooling + Adam + lr 1e-3 + batch 64 + wd 1e-4 + dropout 0.2 + BN + flip 增强`，每次**只改一个**超参（单因子，OFAT），seed=0，共 33 组 + 1 条 base。选 OFAT 而不是随机搜索，原因是 14 小时预算下它更容易归因：每一行的差异只能来自那一个字段。

由于每次只改一个字段，扫描里出现了 13 次「等价于 base」的重跑（`base`、`s1_01`、`s1_04`、`s1_08`、`s1_11`、`s1_14`、`s1_17`、`s1_19`、`s1_22`、`s1_24`、`s1_26`、`s1_30`、`s1_32`），val AUC 全部精确等于 0.984404。这 13 次重复说明**同 seed 同配置可完全复现**（三处 seed 均已固定），也是后面 S3 判据可信的前提。

读法：前四项（lr、optimizer、BN、宽度）覆盖了本项目 90% 的可调空间；后七项的极差全部 ≤0.0062，**在 seed 波动量级（第 4.1 节 0.0002–0.0009）之上但很有限**，继续细调属于收益递减。

### 3.4 两个与预期相反的现象

- **不池化反而变差（0.9782 vs 0.9844）。** 笔记 C3 订正版写的是「医学影像微小结节会在池化中丢失」，据此原以为去掉池化会更好。实测相反。解释：28×28 上去掉池化后感受野与参数利用效率下降，且 GAP 之前的特征图仍带空间噪声，单次 2×2 池化反而起了轻量正则作用。「不堆池化」是对的，「完全不用池化」是过度的——订正版结论需要加这个边界条件。
- **数据增强有害（无增强 0.9851 > flip 0.9844 > flip+rot 0.9821）。** 水平翻转让左右肺互换，标签不变，理论上安全；但旋转会把肺野推到画布边缘、引入大量黑边填充，属于分布外变换。在小数据上，增强带来的分布偏移大于它带来的正则收益。

| 组合 | val AUC | val ACC |
| --- | --- | --- |
| lr 1e-3 / w32（= base） | 0.984404 | 0.9275 |

## 4. 结果评估

### 4.1 S3：三 seed 复跑，判断提升是否真实

S1 只跑 seed=0，最优组相对 base 的 +0.0046 **小于 lr 组自身的极差 0.022**，因此在下结论前必须做重复实验。

| 配置 | n | val AUC 均值 | 样本标准差 | 最小值 | 最大值 | val ACC 均值 | 平均耗时 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| base（w32） | 3 | 0.984537 | 0.000215 | 0.984404 | 0.984785 | 0.9313 | 1.17 min |
| **conv_width=64** | 3 | **0.988645** | 0.000490 | 0.988080 | 0.988956 | 0.9408 | 2.24 min |
| lr 3e-3 | 3 | 0.987127 | 0.000933 | 0.986080 | 0.987870 | 0.9447 | 1.08 min |

**差值 +0.004107，约为 base 标准差的 19 倍（按总体标准差口径 23 倍）。逐 seed 配对比较，三个 seed 全部为正：**

| seed | base | w64 | 差值 |
| --- | --- | --- | --- |
| 0 | 0.984404 | 0.988956 | +0.004552 |
| 1 | 0.984423 | 0.988080 | +0.003657 |
| 2 | 0.984785 | 0.988898 | +0.004113 |

结论：**调参带来的提升是真实且方向一致的，不是种子噪声。**代价是训练时间翻倍（1.17 → 2.24 min）与参数量 ×3.9（19,042 → 74,946）。

同时注意 lr=3e-3 的标准差（0.000933）是 base 的 4.3 倍，并且两个 seed 触发早停（15 轮、17 轮）——**高学习率带来更大方差**，这与 lr 组极差最大的观察一致。若追求稳定交付，`conv_width=64 + lr 1e-3`（低方差）比 `lr 3e-3`（高方差、均值略低）更合适。

### 4.2 最终配置在 val 上的表现

`configs/best.yaml` = base + `conv_width: 64`，seed 0，训练 20 轮，权重取 **val AUC 最高的第 19 轮**（0.9890），不是最后一轮（第 20 轮 0.9837）。这一点必须核对，否则会把一个更差的模型交出去。

### 4.3 独立 test 一次性评测

用 `configs/best.yaml` + `outputs/best.pth`，`--split test` 只执行一次（`results/test_final.csv` 仅 1 行，时间戳 13:46:57，晚于全部调参实验）。

| 指标 | test（624 张） |
| --- | --- |
| AUC | 0.954635 |
| ACC | 0.834936 |
| F1 | 0.882554 |
| 混淆矩阵 | [[134, 100], [3, 387]] |

**val → test 落差：AUC −0.0343、ACC −0.1174；假阳性从 17 例（阴性中 12.6%）涨到 100 例（阴性中 42.7%）。**

这不是代码 bug，有三个可核对的事实支撑：

1. **来源不同，不是随机划分。** MedMNIST 官方说明 train/val 是按 9:1 从 source training set 切分，test 来自**独立的 source validation set**（另一批病人/采集条件）。这是典型的协变量偏移，正对应笔记 C11「领域自适应」。
2. **阳性率先变了。** val 阳性 74.2%，test 只有 62.5%，而模型是在 74% 阳性的先验下训练的，输出概率整体偏高，固定阈值 0.5 在 test 上等于把判定线压低了 → 假阳性暴增。
3. **AUC 只掉 0.034、ACC 掉 0.117，方向一致。** 排序能力（AUC）保持得不错，坏在**校准/阈值**，说明模型学到的特征仍有判别力，问题是概率刻度没对齐。这条差别本身就是一个合格的分析结论，而不是失败。

**为什么不用 S2 更优的 `lr 3e-3 + w64`（val 0.990669）重跑 test：** test 已经用最终配置评过一次。看到 test 结果后再回去挑一个 val 更高的配置、再评第二次，就等于用 test 参与选择，指标不再独立（C1 自测第三题「用训练集调参是看答案」的同一逻辑）。因此该组合只作为遗留改进方向写入第 6 节，并在答辩时主动说明。

## 5. 结论

1. **在固定 SmallCNN 结构内，调参带来稳定、可复现的提升。** base 0.984537 → w64 0.988645，+0.0041（≈19 倍 base 标准差），3 个 seed 全部同向。最有效的两个旋钮是**容量（conv_width 32→64）**与**学习率量级**（1e-3→3e-3 单因子最优，但方差更大）。
2. **机制解释**：宽度翻倍让第一层卷积能同时保留更多强度/纹理滤波器，直接对应 28×28 胸片上「整片肺野浸润」这类粗粒度证据；而不是靠更深的层次堆叠。这与第 2 节 MLP 的表现互为印证——**本任务的判别信息主要是全局统计量**。
3. **敏感性排序（lr > optimizer > BN > conv_width ≫ 其余七项）给出了明确的调参优先级**：预算有限时只动前四项，其余保持默认。后七项极差 ≤0.0062，继续细调是负收益。
4. **结构选择的收益大于调参收益。** MLP（100,738 参数）取得 0.9928，比调参后的 CNN 还高 0.0042。所以「调参能提升」成立，但**调参不能替代结构论证**；本项目真正的上限瓶颈是容量与归纳偏置的匹配，而不是旋钮位置。
5. **val/test 落差是分布问题，不是模型崩了。** AUC 仅掉 0.034、ACC 掉 0.117、假阳性率 12.6%→42.7%，指向先验偏移下的阈值失配（C11）。正确处置是报告并分析，而不是拿 test 回调阈值。
6. 两条与笔记预期相反的实测：**完全不池化更差**、**数据增强有害**。两者都对原结论给出了边界条件，是本次实验最有价值的「订正」。

## 6. 局限与改进方向

| 优先级 | 事项 | 具体做法 | 预计成本 |
| --- | --- | --- | --- |
| 高 | 容量对齐后再比结构与调参 | MLP 宽度扫 64/128/256，与 w32/w64 CNN 在**同等参数量**下对比，分离「容量」与「结构类型」两个因素 | 6 组 × 3 seed，约 25 min |
| 高 | 采纳 S2 最优组合 | `lr 3e-3 + w64` 若作为下一版最终配置，需在新的实验轮次重新只评一次 test（本轮 test 已消耗） | 3 seed + 1 次 test，约 12 min |
| 中 | 阈值与校准分析 | 在 **val** 上画阈值-ACC/F1 曲线，报告「val 最优阈值」与 0.5 的差异；用 val 做 Platt/isotonic 校准后再看 test（只用 val 拟合，不碰 test 标签） | 30 min |
| 中 | 负样本子集上的公平评估 | 按 test 阳性率 62.5% 对 val 做分层重采样，观察 ACC 落差中有多少来自先验差异 | 20 min |
| 低 | 剪枝与蒸馏（C14） | 对 w64 做 `l1_unstructured` 30%/50% 剪枝 + 微调，看 AUC 掉多少；再把 w64 蒸馏到 w16 | 1.5 h |
| 低 | 可解释性（C10） | Grad-CAM 叠加到原图，检查高响应区是否落在肺野而非边框/文字标记 | 1 h |
| 低 | 跨子集泛化 | 换 BreastMNIST / BloodMNIST 复用同一套 `src/`，验证流程可迁移 | 1 h |
