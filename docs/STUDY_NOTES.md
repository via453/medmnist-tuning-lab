# 一、先把主线记住

整个项目其实是一条「从相信到怀疑」的线。心里有这条线，16 页就不会散：

```
我做了个模型（P1-P3）
  ↓
先立规矩：数据怎么分、指标用什么、测试只评一次（P4-P5）
  ↓
第一个问题：调参有没有用？—— 有，但只有 0.0041（P9-P11）
  ↓
第二个问题：那什么更有用？—— 结构（P6-P7）
  ↓
但"结构谁最强"这个结论站得住吗？—— 站不住，容量没对齐（P8）← 全场最值钱
  ↓
第三个问题：0.99 这个分数可靠吗？—— 不可靠，1.5% 扰动就崩（P12-P14）
  ↓
所以我改了三处判断（P15），留下五条能复核的结论（P16）
```

**一句话版本**：我不是在证明"我的模型好"，我是在测量"它好在哪、什么时候会失灵、以及我之前的判断错在哪"。

## 第 2 页 · 五个阶段、79 次训练

**这页为什么存在**：先用规模建立可信度。评委看到"79 次"会本能地认为这是个认真做的项目，而你后面讲 0.0041 时才不会被当成"随便调了调"。

**页面上都是什么**

| 数字 | 怎么来的 |
| --- | --- |
| 79 次训练 | 36（主实验）+ 4（S2 网格）+ 9（S3 三 seed）+ 6（结构对照）+ 18（容量对齐）+ 6（对抗训练）= 79 |
| 46 组有效对照 | 33（S1）+ 4（S2）+ 9（S3） |
| 1 次测试 | `results/test_final.csv` 只有一行，时间戳晚于所有调参实验 |

**名词**

| 页面表述 | 术语 | 一句话定义 |
| --- | --- | --- |
| 单因子扫描 | one-factor-at-a-time (OFAT) | 每次只改一个超参数、其余固定，看这个参数单独能造成多大差异 |
| 对照实验 | controlled experiment | 只让一个变量变化，其余条件完全相同，才能把差异归因到这个变量 |
| 随机种子 | random seed | 控制所有随机性（初始化、打乱顺序、增强）的起点；同种子必得同一结果 |
| 失败组留痕 | — | 效果差的配置也写进结果表，否则只在成功的配置里比较，等于挑选证据 |

**为什么是这个顺序**：先分数据（不定划分后面全废）→ 再写模型（没有模型没法扫）→ 再扫参数（不知道哪些参数重要就没法设计后续）→ 再验稳定（一次结果不可信）→ 最后测试（只有一次机会，必须放到最后）。

**对应笔记**：C1（实验设计的基本逻辑）、C16（把模块串成流程）。

**脱稿只说这几句**
> 79 次训练分五个阶段，每个阶段回答上一阶段答不了的问题。最关键的一条：79 次里只有 1 次碰测试集，其余 78 次都在 524 张验证集上完成。

## 第 4 页 · 任务、数据与三个硬约束

**这页为什么存在**：先定口径。不先说清"用什么指标、怎么分数据"，后面所有数字都可以被质疑"你换个算法结论就变了"。

**页面上都是什么**

| 元素 | 含义 | 为什么是这个值 |
| --- | --- | --- |
| 28×28 单通道 | 灰度图，784 个像素 | MedMNIST 官方统一规格，CPU 也能跑 |
| 二分类 normal / pneumonia | 阳性 = 肺炎 | 医学筛查场景，漏诊代价 > 误诊 |
| AUC 主指标 | 见下 | 与阈值无关，不受类别比例影响 |
| 4,708 / 524 / 624 | 官方划分 | 不重切才能和公开结果对比 |
| 74.2% → 62.5% | 阳性率 | 验证集和测试集来源不同，这是第 13 页的伏笔 |

**名词（这页最重要）**

| 名词 | 人话 | 严格一点 |
| --- | --- | --- |
| **AUC** | 随便挑一个病人和一个健康人，模型把病人排在前面（判为肺炎概率更高）的概率 | ROC 曲线下面积；0.5 = 瞎猜，1.0 = 完全分对。**与判定阈值无关** |
| **ACC** | 判对的百分比 | 受阈值和类别比例双重影响，所以不能当主指标 |
| **阳性率 / 先验** | 样本里病人占多少 | prevalence，`P(y=1)`。会直接改变固定阈值下的误报数 |
| **阈值** | 判定的分数线 | 概率 ≥ 0.5 判肺炎；调它会在误报和漏诊之间移动误差 |

**为什么主指标是 AUC 而不是 ACC**：ACC 在类别不平衡时会被"全判多数类"骗到（测试集 62.5% 是肺炎，全判肺炎就有 62.5% ACC）。AUC 衡量排序能力，不依赖你选哪个阈值。

**对应笔记**：C1（指标怎么选）、C11（先验/类别比例的影响）。

**脱稿只说这几句**
> 任务是 28×28 胸片二分类，主指标用 AUC 而不是准确率——因为 AUC 与阈值无关，也不受病人比例影响。数据用官方划分，验证集选择、测试集只进一次。这里埋一个伏笔：两边阳性率从 74.2% 掉到 62.5%，第 13 页会算它造成多少落差。

## 第 5 页 · 实验设计 33 / 4 / 9 / 1

**这页为什么存在**：这页是整份工作的方法论核心。它回答"凭什么相信你那个 0.0041"。

**页面上都是什么**

| 数字 | 含义 |
| --- | --- |
| 33 | S1 单因子：11 个超参数，每个改 1–3 档 |
| 4 | S2 网格：lr × conv_width 两两组合 |
| 9 | S3：3 个配置 × 3 个种子 |
| 1 | test 评测，只报告，不回头改 |

**名词**

| 页面表述 | 术语 | 定义 / 在本项目里的具体值 |
| --- | --- | --- |
| 单因子扫描看不到交互 | interaction effect | lr 单独最优不代表 lr+width 组合最优，因为两个参数会互相影响 |
| 配对比较 | paired comparison | 同一种子下 base 与 w64 相减，消掉"这个种子本身偏强/偏弱"的影响 |
| 种子标准化 | seed control | random / numpy / torch 三处都设，保证复现 |
| 早停 | early stopping | 验证集指标连续 5 轮不升就停，防止过拟合 |
| 组内极差 | range within group | 同一超参数各档之间的最大值减最小值；lr 的极差 0.0220 |
| 判定标准 | decision rule | 差值必须 > 数倍标准差，且三个种子同向，才可称"提升" |

**这页最关键的一层逻辑**：33 组单因子只能**排序**（谁是敏感参数），不能**下结论**（谁更好）。因为单次差值 0.0046 小于组内极差 0.0220——这个差在噪声范围内。所以才有 S3。

**对应笔记**：C1（实验设计）、C2（优化技巧——这 33 组里 lr、optimizer、BN、scheduler 的极差就是 C2 的实测数字）。

**脱稿只说这几句**
> 33 组单因子只能排序，不能下结论——单次差 0.0046，而组内极差有 0.0220，这个差淹没在噪声里。所以要 9 组配对复跑，最后才进测试集。这一页是整份工作的判定标准。

## 第 6 页 · 三种结构

**这页为什么存在**：这是唯一一页纯理论页。它要讲清"三个模型到底差在哪"，后面第 7、8 页的结论才有落脚点。

**核心一句话**：三个模型唯一被改变的变量是**信息在什么尺度上被混合**。

**页面上都是什么**

| 模型 | 参数 | 页面上的表述 | 术语对应 |
| --- | --- | --- | --- |
| MLP | 100,738 | 展平为 784 维、第一层即混合全图 | flatten + fully-connected；全局感受野 |
| SmallCNN | 74,946 | 两层 3×3 卷积 + BN、一次 2×2 池化、GAP | convolution / batch norm / pooling / global average pooling |
| TinyViT | 71,554 | 7×7 patch、cls token、2 层 pre-norm、4 头 | patch embedding / class token / self-attention / pre-LN / FFN |

**名词逐个拆**

| 名词 | 人话 | 严格定义 |
| --- | --- | --- |
| **感受野** | 一个神经元"能看到"原图多大一块 | 输出一个点所依赖的输入区域大小。两层 3×3（无中间池化）= 3 + 2 + 2 = **9×9** |
| **卷积核 3×3** | 一个 3×3 的小放大镜 | 在图上滑动，每处做加权求和；参数共享所以省参数 |
| **BN（批归一化）** | 每层输出先做一次标准化，让数值稳定 | 对每个通道在一个 batch 内减均值除标准差，再学两个可调参数 |
| **池化** | 把 2×2 的格子压成一个数 | 下采样，降低分辨率、扩大感受野、减少参数 |
| **GAP** | 把整张特征图取平均成一个数 | global average pooling，替代全连接层，参数更少 |
| **patch** | 把图切成小块，每块当一个"词" | 28÷4 = 7，所以是 7×7 = 49 个 patch |
| **cls token** | 额外加一个"汇总位" | 一个可学习的向量，最后用它做分类 |
| **自注意力** | 每个 patch 都去问其他所有 patch"你和我有关吗" | `softmax(QKᵀ/√d)V`，任意两点一步可达 |
| **O(n²)** | 49 个 patch 要两两算，成本随块数平方增长 | 这就是 ViT 训练时间 2.4 min、CNN 1.2 min 的原因 |
| **pre-norm** | 先标准化再进注意力 | `x + Attn(LN(x))`，比 post-norm 更稳，小模型常用 |

**为什么要讲"9×9 覆盖不到九分之一"**：28×28 = 784，9×9 = 81，81/784 ≈ 10.3%。而本任务的判别证据是**整片肺野的弥漫性浸润**，是全局统计量。所以"看不到全图"在理论上就是劣势——这是第 7 页实验的假设来源。

**对应笔记**：C3（卷积为什么省参数、参数量怎么手算、池化）、C4（自注意力）、C5（Transformer）。

**脱稿只说这几句**
> 三个模型唯一的差别是信息在多大的范围里被混合。MLP 第一层就能混合全图，CNN 两层叠起来只看得到 9×9，ViT 每个 patch 都能直接问其他 patch。而这个任务的证据是整片肺野的浸润，属于全局统计量——所以"能不能看到全图"可能比"看得多细"更重要。

## 第 7 页 · 结构对比

**这页为什么存在**：给第一个结论，同时**主动说出它不能证明什么**。这是评委最看重的部分：知道自己的证据边界在哪。

**页面上都是什么**

| 项目 | 值 |
| --- | --- |
| TinyViT | 0.9935 ± 0.0006（71,554） |
| MLP | 0.9928 ± 0.0001（100,738） |
| SmallCNN | 0.9886 ± 0.0004（74,946） |
| 统一设置 | Adam 1e-3 / batch 64 / 20 轮 / 早停 5 |

**名词**

| 名词 | 定义 | 在这里的用处 |
| --- | --- | --- |
| 均值 ± 标准差 | 3 个种子的中心与离散程度 | 判断两个模型差距是否超过噪声 |
| 统计显著 | 差距大于随机波动 | ViT 与 MLP 差 0.0007，而 std 就有 0.0006，所以不算显著 |
| 混淆变量 | 除想研究的因素外还变了的东西 | 这里就是**参数量**：三者 7.2 万 / 10 万 / 7.5 万，本来就不齐 |

**能支持 / 不能支持，分开说的意义**：
- 能支持：全局混合 > 局部卷积（差 0.005–0.009，远超 std）
- 不能支持：ViT > MLP（差 0.0007，但参数量差 3 万）

**对应笔记**：C3 / C4 / C5，以及 C1（什么叫"显著"）。

**脱稿只说这几句**
> 结果是 ViT 0.9935、MLP 0.9928、CNN 0.9886。能说的只有一句：全局混合比局部卷积好 0.005 到 0.009。但 ViT 和 MLP 只差 0.0007，而参数量差了 3 万——所以"ViT 最优"这个结论我不能下。下一页我去把它证伪。

## 第 8 页 · 参数量对齐（重点①）

**这页为什么存在**：这是全场最能体现科研素养的一页——**用新实验推翻自己上一轮的结论**。

**页面上都是什么**

| 容量档 | MLP | SmallCNN | TinyViT |
| --- | --- | --- | --- |
| ~1.9 万 | 0.9922（18,890） | 0.9845（19,042） | 0.9922（19,394） |
| ~7.2 万 | 0.9927（71,619） | 0.9879（72,641） | 0.9935（71,554） |

（括号内是实际参数量，不是目标值——因为宽度只能取整数，没法精确命中）

**名词**

| 名词 | 人话 | 严格定义 |
| --- | --- | --- |
| **容量 / 参数量** | 模型能装多少东西 | 可训练参数的个数；`sum(p.numel() for p in model.parameters())` |
| **容量对齐** | 把三个模型的参数量强行调到同一水平 | 控制变量：只有"结构"变，容量不变，才能把差异归因给结构 |
| **反解** | 不知道宽度该设多少，就反过来搜 | 给定目标参数量，搜索 width/dim 使实际参数量最接近目标（`--dry-run` 就是这么做的） |
| **饱和** | 再加参数也没用 | 1.9 万 → 7.2 万，MLP 只涨 0.0005，说明容量已饱和 |

**这页的三条结论，措辞要精确**

1. **CNN 落后是结构性的**：两档都低 0.005–0.008；7.2 万档它参数最多（72,641）却最差。→ "加参数无法弥补"。
2. **"ViT 最优"站不住**：ViT 与 MLP 差 0.00008（1.9 万档）/ 0.00085（7.2 万档），都在 std 之内。
3. **容量在 1.9 万就饱和**：1.9 万参数的 MLP 与 7.2 万参数的 ViT 只差 0.0013。

**修正后的表述**：全局信息混合 > 局部卷积，**注意力的额外贡献不显著**。

**对应笔记**：C3（参数量手算——你能手算 19,042 和 74,946，所以能反解）、C1（控制变量法）。

**脱稿只说这几句**
> 上一轮我说"ViT 最优"，但那三个模型参数量从 1.9 万到 10 万，本来就不齐。这次我按真实参数量反解每个结构的宽度，压到 1.9 万和 7.2 万两档再比。结果两条：CNN 落后是真的，加参数也补不回来；但 ViT 和 MLP 的差只有万分之几，落在种子波动里——"ViT 最优"站不住。真正起作用的不是注意力，是"能不能看到全图"。

## 第 9 页 · 调参 +0.0041

**这页为什么存在**：回答"调参有没有用"。答案是"有用，但小"，而"小"必须用判据撑住。

**页面上都是什么**

| 数字 | 含义 |
| --- | --- |
| +0.0041 | 三次配对差值的平均 |
| 19× | 差值 ÷ base 的标准差（0.000215）≈ 19 |
| 3/3 | 三个种子方向全部为正 |

**名词**

| 名词 | 定义 |
| --- | --- |
| **配对差值** | 同 seed 下 w64 − base，消掉种子本身强弱的影响 |
| **效应量** | 差值除以标准差；19 倍意味着这个差不是噪声能解释的 |
| **标准差 ddof=1** | 样本标准差（除以 n−1），n=3 时比总体标准差略大，更保守 |

**为什么要三个判据**：只看均值会被单个异常种子带偏；只看倍数不知道方向是否一致；只看方向不知道幅度。三个都满足才叫提升。

**边界**：这个提升只发生在 SmallCNN 内部。换成全局混合结构后宽度几乎不起作用——这是第 8 页容量饱和的另一个侧面。

**对应笔记**：C1（显著性判断）、C2（conv_width 属于容量，不是优化技巧）。

**脱稿只说这几句**
> 固定结构，只把宽度 32 改到 64，三次配对：平均 +0.0041，是标准差的 19 倍，三个种子全部同向。三个判据都满足才敢写"提升"。但这个提升只在 CNN 内部有效。

## 第 12 页 · Grad-CAM

**这页为什么存在**：防守。证明模型看的是病灶，不是黑边、体位标记这类"捷径特征"。如果它能靠边框判断，前面所有精度都不可信。

**页面上都是什么**

| 数字 | 含义 |
| --- | --- |
| 0.382 | 判为肺炎时，注意力落在边框 4 像素环里的比例 |
| 0.490 | 边框环本身占整张图的面积比例 |
| 0.78× | 0.382 ÷ 0.490，小于 1 说明注意力偏中央 |

**名词**

| 名词 | 定义 |
| --- | --- |
| **Grad-CAM** | 用最后一层卷积的梯度给每个通道加权，得到一张"哪里重要"的热力图 |
| **hook** | PyTorch 的前向/反向钩子，可以在不改编模型代码的前提下取出中间层的值和梯度 |
| **上采样** | 把 14×14 的热图放大回 28×28，才能和原图对齐 |
| **富集倍数** | 响应占比 ÷ 面积占比；=1 表示均匀，>1 表示偏向该区域 |

**为什么 0.382 不能单独看**：边框面积占 0.490，如果模型完全随机，边框里也会有 49% 的注意力。所以必须比"相对于面积"的倍数。

**对应笔记**：C10（可解释性）。

**脱稿只说这几句**
> 热图落在肺野，不在四边。定量上边框响应 0.382、面积 0.490，比值 0.78，小于 1，说明注意力偏中央。这个指标必须和面积一起报，否则 0.382 会被误读成"很依赖边缘"。

## 第 13 页 · test 落差（重点②）

**这页为什么存在**：这是整个项目"最诚实"的一页。它承认模型在真实数据上掉 11 个点，并且把落差拆开，说明哪部分是数据的问题、哪部分是模型的问题。

**页面上都是什么**

| 数字 | 含义 |
| --- | --- |
| 0.9546 | test AUC（624 张，只评一次） |
| 0.8349 | test ACC（阈值固定 0.5） |
| −0.1174 | val ACC 0.9523 → test ACC 0.8349 |
| 23 → 100 | 假阳性个数，三倍多 |
| 11% / 89% | 先验能解释的部分 / 分布偏移解释的部分 |

**拆解的三行**

| 场景 | ACC | 说明 |
| --- | --- | --- |
| val 全量（阳性 74.2%） | 0.9523 | 原始验证集 |
| 只把先验对齐到 62.5% | 0.9399 ± 0.0036 | 模拟"病人比例变了" |
| 真实 test（阳性 62.5%） | 0.8349 | 还差 0.1050 |

**名词**

| 名词 | 人话 | 严格定义 |
| --- | --- | --- |
| **分布偏移** | 换了一家医院 | 训练分布 P(x) 与测试分布不同；这里指拍片设备、体位、人群构成不同 |
| **先验 / 类别比例** | 样本里病人占多少 | P(y)。固定阈值 0.5 时，先验下降会让更多阴性被判成阳性 |
| **协变量偏移** | 输入的样子变了，标签规则没变 | P(x) 变、P(y\|x) 不变；属于分布偏移的一种 |
| **自助抽样 bootstrap** | 有放回地重抽，模拟"如果比例变了会怎样" | 从 val 里按 62.5% 阳性率重采样 200 次，取 ACC 的均值与标准差 |
| **阈值失配** | 阈值是在 74.2% 的验证集上定的，搬到 62.5% 就不合适了 | 固定 0.5 不变，等于沿用了旧的先验假设 |

**为什么"调阈值不是解法"**：把阈值调低，误报减少但漏诊增加，总误差只是换个位置。所以只能承认这是分布问题，不是调参能解决的。

**对应笔记**：C11（领域自适应）、C1（测试集只评一次）。

**脱稿只说这几句**
> 测试集只评一次：AUC 0.9546，ACC 0.8349，比验证集掉 0.1174，假阳性从 23 涨到 100。我把验证集的阳性率对齐到 62.5% 重采样 200 次，ACC 只掉到 0.9399——先验只解释 11%，剩下 89% 是真实的分布偏移：设备、体位、人群都不一样。所以调阈值不是解法，只是把误差挪个位置。图上这两张是验证集的，测试集只有一行数字，为了守住只评一次没重复出图。

## 第 14 页 · 对抗训练（重点③）

**这页为什么存在**：回答"0.99 可靠吗"。答案是"不可靠"，并且给出一个可量化的修补方案和它的代价。

**页面上都是什么**

| 数字 | 含义 |
| --- | --- |
| 0.47 → 0.87 | ε=0.03 处 AUC：干净训练 vs 对抗训练 |
| −0.0081 | 干净 AUC 的代价（0.9886 → 0.9805） |
| 79% | 降幅收窄比例：(0.9886−0.47) → (0.9805−0.87) |
| ε ≈ 0.08 | 保护范围上界；ε≥0.2 两组都归零 |

**名词**

| 名词 | 人话 | 严格定义 |
| --- | --- | --- |
| **FGSM** | 朝"让它判错"的方向，给每个像素推一小步 | Fast Gradient Sign Method：`x' = x + ε·sign(∇ₓL)`，只走一步 |
| **ε（epsilon）** | 推多大；0.03 = 量程的 3%，实际像素变化约 1.5% | L∞ 扰动半径，每个像素最多改 ε |
| **对抗样本** | 人眼看不出来、模型却判错的图 | 加了微小扰动后预测翻转的输入 |
| **对抗训练** | 训练时把对抗样本混进去，让它提前见过 | 每个 batch 取一半样本做 FGSM 再算损失 |
| **鲁棒性** | 抗干扰能力 | 在扰动下指标下降的幅度 |
| **单步 / 迭代** | FGSM 只走一步，PGD 走多步 | PGD 更强，所以 FGSM 训练出来的保护范围有限 |

**为什么保护只在 ε≈0.08 以内**：训练时只见过 ε=0.03 的扰动，模型学到的是这个邻域的形状。超出邻域就没有约束了。这是单步攻击训练的通病，也是下一步要换 PGD 的原因。

**对应笔记**：C9（对抗攻击）。

**脱稿只说这几句**
> 推到 ε=0.03，也就是 1.5% 的像素变化，干净模型的 AUC 从 0.9886 掉到 0.47，基本是反着判。对抗训练把同一点的 AUC 拉回 0.87，代价是干净精度掉 0.0081。但保护只到 ε 约 0.08，再大两组都崩——所以更严格的做法应该是迭代式的 PGD。这页想说一句话：99% 准确率必须附带扰动假设。

# 五、五分钟问答准备

按被问概率排序。每题给一句话核心 + 一句补充。

### 关于结构（最可能被问）

**Q：ViT 到底赢没赢？**
赢了 CNN，和 MLP 打平。差 0.0007 在种子波动内。真正起作用的是"全局混合"，不是注意力本身。

**Q：为什么你的 CNN 这么弱？是不是没调好？**
两档参数量都试过，7.2 万档它参数最多结果最差。原因是感受野 9×9 覆盖不到全图九分之一，而任务是弥漫性浸润——是结构不匹配，不是没调好。
（可以补一句：如果是局部病灶如结节，结论很可能反过来。）

**Q：为什么不用 ResNet / 预训练模型？**
28×28 灰度图，ResNet 的下采样会把 28 压到 7 甚至 1，结构不匹配；预训练权重是 224×224 自然图像，迁移过来收益有限。

### 关于调参结论

**Q：+0.0041 有意义吗？**
单个数字没有意义。有意义的是它大于种子波动的 19 倍且 3 个种子同向。这个判据可以迁移到任何调参实验。

**Q：为什么不做网格搜索全覆盖？**
33 组单因子 + 4 组两两组合是预算内的最优解。11 个参数做全网格是 3^11 量级，CPU 上不可能。

**Q：为什么不做交叉验证？**
为了和官方划分对齐；而且"测试只评一次"这条纪律下，交叉验证的"验证"就变成测试了。验证集 524 张确实少，所以用三个种子补。

### 关于评测

**Q：验证集 0.95、测试集 0.83，是不是过拟合了？**
不是。过拟合表现为训练高验证低；这里是验证高测试低，属于分布偏移。拆解显示先验只解释 11%，89% 是设备/体位/人群差异。

**Q：为什么不调阈值让测试集好看一点？**
调阈值只是把误报换成漏诊，总误差不变。而且那等于用测试集做决策，违反只评一次。

### 关于鲁棒性

**Q：对抗训练值不值？**
看场景。筛查场景宁可牺牲 0.008 的干净精度，也不能被 1.5% 的噪声骗过去。但当前只护到 ε≈0.08，需要换 PGD。

**Q：为什么 ε=0.03 就崩了？**
单步扰动在 28×28 小图上相对影响更大（每个像素改 3%，但图本身只有 784 个像素）；而且这个模型没有做过任何正则化的鲁棒性训练。

### 关于可解释性

**Q：Grad-CAM 能证明模型真的在推理吗？**
不能证明因果，只能说明注意力落点。它能排除"靠边框作弊"这一类捷径，但不能保证学到的是医学特征。

### 可能的追问（准备一句就够）

**Q：这个项目最弱的一环是什么？**
对抗训练用了干净 AUC 早停，seed 0/1 在第 12 轮被截断，所以 0.8711 是保守下界。

**Q：如果重做一遍，先改哪一步？**
先固定早停指标 = 最终目标，再碰模型。这次最大的返工成本不是训练，是口径没写死。

不是精度。是把"调参收益 vs 结构收益"用同一套预算、同一套判据量了出来，并且公开了一个被自己推翻的结论。

# 七、附录：6 分半连续版

把上面每页的"关键句"连起来，就是一段可以完整练的串词。约 1,450 字，正常语速 6 分半。
**练的时候不要背字，记每段的第一句和最后一个数字**，中间自然衔接。

> 各位老师好，我是 Zelvia。汇报题目是 MedMNIST 医学影像分类调参实验室。
> 一句话概括：我用胸片二分类这个任务跑了 79 次训练，回答三个问题——调参有没有用、结构是不是更重要、一个 0.99 的模型有多脆弱。
>
> 先说规模。79 次训练分五个阶段：划分数据、写三种结构、单因子扫描 33 组、三 seed 复跑 9 组、最后测试一次。最关键的一条纪律是：79 次里只有 1 次碰测试集，其余 78 次都在 524 张验证集上完成。
>
> 这一页是全场的地图，四段加一条回路。蓝色虚线是调参回路，只走验证集——这就是为什么我的测试结果全程只出现一次。
>
> 任务很直接：28×28 灰度胸片，判断正常还是肺炎。主指标用 AUC 而不是准确率，因为 AUC 与阈值无关，也不受病人比例影响。数据用官方划分。这里埋一个伏笔：验证集阳性率 74.2%，测试集 62.5%，第 13 页我会算它到底造成多少落差。
>
> 设计是 33、4、9、1。33 组单因子只能排序，不能下结论——单次差 0.0046，而组内极差有 0.0220，这个差淹没在噪声里。所以要 9 组配对复跑，最后才进测试集。这一页是整份工作的判定标准。
>
> 接下来是三种结构。它们唯一的差别，是信息在多大的范围里被混合。MLP 把图展平，第一层就能混合全图；CNN 两层 3×3 叠起来只看得到 9×9，覆盖不到九分之一；ViT 把图切成 49 块，每块都能直接问其他块。而这个任务的证据是整片肺野的浸润，属于全局统计量——所以"能不能看到全图"可能比"看得多细"更重要。
>
> 结果是 ViT 0.9935、MLP 0.9928、CNN 0.9886。能说的只有一句：全局混合比局部卷积好 0.005 到 0.009。但 ViT 和 MLP 只差 0.0007，参数量却差了 3 万，所以"ViT 最优"这个结论我不能下。
>
> 所以下一页我去把它证伪。我按真实参数量反解每个结构的宽度，压到 1.9 万和 7.2 万两档再比。结果两条：第一，CNN 落后是真的，两档都低 0.005 到 0.008，而且 7.2 万档它参数最多、结果最差——加参数补不回来；第二，"ViT 最优"站不住，ViT 和 MLP 的差只有万分之几，落在种子波动里。更关键的是，1.9 万参数的 MLP 和 7.2 万参数的 ViT 只差 0.0013，说明容量在 1.9 万就饱和了。真正起作用的是"能不能看到全图"，不是注意力本身。
>
> 回到调参。固定结构，只把宽度从 32 改到 64，三次配对：平均 +0.0041，是标准差的 19 倍，三个种子全部同向。三个判据都满足，才敢写"提升"。但这个提升只在 CNN 内部有效，换成全局混合结构后宽度就不起作用了——这就是刚才容量饱和的另一个侧面。三个种子逐一配对，差值是 0.0046、0.0037、0.0041，方向一致；只报单次运行的话，这个差和噪声是分不开的。
>
> 最终配置只有六行，全来自验证过的结论，删掉的比留下的多。权重取第 19 轮而不是最后一轮——第 20 轮反而掉了 0.0053。
>
> 有人会问：这个模型是靠看病灶，还是靠看黑边？热图显示注意力落在肺野。定量上，边框响应占 0.382，而边框面积本身就占 0.490，比值 0.78，小于 1，说明注意力偏中央。这个指标必须和面积一起报，否则 0.382 会被误读成"很依赖边缘"。
>
> 测试集只评一次：AUC 0.9546，准确率 0.8349，比验证集掉 0.1174，假阳性从 23 涨到 100。落差从哪来？我把验证集阳性率对齐到 62.5% 重采样 200 次，准确率只掉到 0.9399——先验只解释 11%，剩下 89% 是真实的分布偏移：设备、体位、人群都不一样。所以调阈值不是解法，只是把误差挪个位置。图上这两张是验证集的，测试集只有一行数字，为了守住只评一次没有重复出图。
>
> 那这个 0.99 可靠吗？推到 ε=0.03，也就是 1.5% 的像素变化，干净模型的 AUC 从 0.9886 掉到 0.47，基本是反着判。对抗训练把同一点拉回 0.87，代价是干净精度掉 0.0081。但保护只到 ε 约 0.08，再大两组都崩——所以更严格的做法是迭代式的 PGD。这一页想说一句话：99% 准确率必须附带扰动假设。
>
> 有三处判断被实验推翻了：完全去掉池化反而更差；加旋转增强反而更差，因为把肺野推出了画布；ViT 最优在容量对齐后站不住。三处都改成了带条件的表述——结论范围变窄了，但每一条都能用结果表复核。
>
> 收口。五条结论：调参有效但小；瓶颈不在超参数而在结构；结构差异是信息混合的尺度；精度和鲁棒性是两回事；落差主要来自分布。两条局限我先说清楚：只做分类、单数据集、20 轮预算。一条纪律：测试只评一次，所以更好的配置我也没采纳。
>
